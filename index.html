Tata Cara Drag & Drop, Setup Database Google Spreadsheet, & Navigasi

1. Cara Memasukkan Data Excel (Cukup Drag & Drop)

Anda tidak perlu input manual. Cukup seret (drag) file Excel (.xlsx / .csv) langsung ke layar browser ini. Sistem otomatis mendeteksi:

  • Format Rekap Harian: Kolom TANGGAL, NAMA TELAK, MANDOR, LOKAL, BRAND, GARAPAN, 8 Kriteria Cacat (CW s/d MM).
  • Format Kartu Giling Gudang 3: Baris pekerja dengan kolom singkatan CW, PK, LK, TK, MT, MD, AT, MM.
  • Format Master Mandor & Lokal: Kolom NAMA LOKAL, NAMA MANDOR, BRAND.

2. Cara Bikin Link Database Spreadsheet (Agar Data Tidak Hilang)

Agar data tersimpan permanen di cloud dan bisa dibuka di HP/laptop lain, ikuti 5 langkah mudah ini:

  1. Buka Google Spreadsheet baru di browser: sheets.new
  2. Klik menu Ekstensi (Extensions) > Apps Script.
  3. Hapus semua kode bawaan, lalu Paste script backend (klik tombol "Salin Script" di atas).
  4. Klik Deploy (Terapkan) > New deployment > pilih jenis Web app. Ubah Who has access menjadi Anyone (Siapa saja), lalu klik Deploy.
  5. Salin Web app URL yang muncul (berakhiran /exec), lalu di dashboard ini klik tombol "Database Sheet" di header atas dan simpan URL tersebut!
💡 Hasilnya: Setiap kali Anda men-drag Excel baru, data otomatis tersimpan langsung ke Google Spreadsheet Anda secara realtime!

3. Kustomisasi Menu & Cetak Laporan

Gunakan tombol "Atur Menu" di header untuk mengubah urutan menu, mengganti nama kriteria, atau mengatur batas toleransi mutu (misal batas merah > 2%). Untuk mencetak atau export PDF, klik tombol "Cetak".
